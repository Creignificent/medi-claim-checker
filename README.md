# Medi-Claim Checker

Free, simple educational tool to help seniors review Medicare claims, spot unauthorized bills for medical equipment, and know how to report them.

## Features
- Interactive claim checker
- Downloadable checklists and guides
- Senior-friendly design (large text, high contrast, big buttons)
- Printable poster, cards, and tablet guide
- Fully responsive

## Live Site
Deploy this static site to Vercel for free.
